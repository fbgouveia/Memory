# FGSS Gestor de Inteligência Competitiva Aplicada

Vertente de memória da **FGSS.io**. Absorve conhecimento de fontes legítimas,
destila princípios, produz requisitos originais e escala inteligência
competitiva para o produto FGSS.io.

## Identidade

Este gestor **não** é um apêndice do dossiê TheFounderOS. O TheFounderOS foi o
primeiro concorrente absorvido; o gestor é a entidade FGSS.io que governa
dossiês, pesquisas, fundação e memória canônica.

## Estrutura

- `FGSS OS/`: dossiê do concorrente TheFounderOS (baseline 15/08/2026,
  audit PASS, 467 arquivos, ~10MB). Será renomeado para
  `competitors/<nome>/` quando o 2º concorrente chegar — motivo concreto,
  não hipotético.
- `foundation/`: modelagem FGSS.io (Invariant Engine, Capability Registry,
  Memory Promotion, Blueprint SDK). Especificação viva até o repo FGSS.io
  ser localizado.
- `research/`: pesquisas de mercado, tecnologia, economia e produto. Cada
  pesquisa segue o protocolo fonte → snapshot → hash → claim → proveniência.

## Princípios

1. **Verdade antes de apresentação**: estados reais, conectores honestos.
2. **Classificação rigorosa**: todo item é `observation`, `commercial_claim`,
   `independent_signal`, `inference` ou `unknown`. Nunca vira fato automático.
3. **Ausência de prova é `unknown`**, nunca zero, nunca negação absoluta.
4. **Adapte princípios; não clone expressão** (marca, copy, layout, imagens,
   comunidades, dados pessoais).
5. **Proveniência obrigatória**: todo claim tem URL, data, hash SHA-256 e
   fonte. Sem proveniência, é `unknown`.
6. **Escrita externa exige gate**: sandbox, aprovação, trilha de auditoria.
7. **Não inferir receita** por seguidores, stars, `joined`, reviews ou
   member count.
8. **Custos de períodos diferentes não se somam**.
9. **Código MIT não licencia marca, copy, site, fotos, vídeos ou ativos
   comerciais.**
10. **O FGSS.io supera por governança, evidence graph, execução comprovada e
    valor auditável** — não por quantidade de agentes, logos ou claims.

## Inicialização obrigatória

1. Leia `HANDOFF.md` para estado atual do gestor.
2. Antes de tocar o dossiê TheFounderOS, leia `FGSS OS/HANDOFF.md` e
   `FGSS OS/AGENTS.md` integralmente.
3. Para novas pesquisas, leia `research/AGENTS.md`.
4. Para modelagem FGSS.io, leia `foundation/AGENTS.md`.
5. Consulte `PENDENCIAS.md`, `ATUALIZACOES.md` e `DESCOBERTAS.md` globais
   do repo `Memory` para contexto do ecossistema.

## Fronteira

- O gestor não conecta contas, solicita OAuth nem executa operações externas.
- O gestor não declara integração global sem validar sessão nova.
- O gestor não modifica o dossiê do concorrente sem registrar delta e
  preservar baseline.
- O gestor não implementa F1-F5 sem o repo real do FGSS.io localizado e
  autorizado.

## Segurança

- Nunca ler, copiar ou registrar valores de `.env`, chaves, tokens ou senhas.
- Nunca salvar cookies, tokens, fingerprints ou conteúdo de perfis privados.
- Não fazer login, compra, submissão de formulário, DM, ingresso em
  comunidade, bypass ou teste de vulnerabilidade contra fontes.
