​ Configuration Steps
Set Up LLM Connection
Enter a Connection Name (e.g., OpenAI )
Select your model provider: openai or azure
Select models you’d like to use in your Studio-generated Crews We recommend at least gpt-4o , o1-mini , and gpt-4o-mini
Add your API key as an environment variable: For OpenAI: Add OPENAI_API_KEY with your API key For Azure OpenAI: Refer to this article for configuration details
Click Add Connection to save your configuration
Verify Connection Added
Configure LLM Defaults
Select default models for agents and other components
Set default configurations for Crew Studio
