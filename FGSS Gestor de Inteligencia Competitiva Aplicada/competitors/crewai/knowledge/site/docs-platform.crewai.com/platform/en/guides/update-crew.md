Updating a Crew on CrewAI AMP
Copy page Copy page
​ Why Update Your Crew?
You want to update the code with a latest commit you pushed to GitHub
You want to reset the bearer token for security reasons
You want to update environment variables
​ 1. Updating Your Crew Code for a Latest Commit
Navigate to your crew in the CrewAI AMP platform
Click on the Re-deploy button on your crew details page
​ 2. Resetting Bearer Token
Navigate to your crew in the CrewAI AMP platform
Find the Bearer Token section
Click the Reset button next to your current token
​ 3. Updating Environment Variables
First access the deployment page by clicking on your crew’s name
Locate the Environment Variables section (you will need to click the Settings icon to access it)
Edit the existing variables or add new ones in the fields provided
Click the Update button next to each variable you modify
Finally, click the Update Deployment button at the bottom of the page to apply the changes
​ After Updating
The system will rebuild and redeploy your crew
You can monitor the deployment progress in real-time
Once complete, test your crew to ensure the changes are working as expected
