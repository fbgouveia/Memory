How To Use AI Agents To Create a Workout Plan - CrewAI Flows https://www.youtube.com/watch?v=NWOoGPKfisg Tyler AI | 0:15:12 | 2025-05-18
This video walks you through creating a seven-step automation flow in CrewAI, using Composio.dev to hook up tools like Google Drive and Slack. The main goal? To build an automatic workout planner. Here’s how it breaks down: first, it sets up and manages a folder in Google Drive. Then, research and summarization agents jump in to gather and crunch all the necessary info. After that, the system generates your workout plans in both .doc and .csv files, saves them all nice and tidy in that Drive folder, and pings you on Slack with an update. The beauty of this flow is how it ensures data moves smoothly from one stage to the next, and Composio makes integrating these tools a breeze – no extra coding needed! Oh, and you’ll also pick up some cool stuff about async execution along the way.
