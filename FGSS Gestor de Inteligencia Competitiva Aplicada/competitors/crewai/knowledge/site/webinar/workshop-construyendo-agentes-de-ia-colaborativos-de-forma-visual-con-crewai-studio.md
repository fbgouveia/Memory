About
CrewAI Studio es el primer editor visual y copiloto de IA para crear equipos de agentes capaces de automatizar tareas complejas y que consumen mucho tiempo. Ahora, cualquier persona puede crear y ejecutar crews potentes de agentes en pocos minutos — desde profesionales de negocio hasta ingenieros de IA.‍Esta sesión será un workshop virtual y práctico. Explicaremos cómo funciona Studio con instrucciones paso a paso en vivo y realizaremos ejercicios para crear, ejecutar, rastrear ( trace ) y desplegar ( deploy ) un crew de agentes en tiempo real.
What you’ll learn
Crear crews de agentes usando lenguaje natural
Usar el asistente de IA y la interfaz de drag & drop para modificar crews
Crear herramientas personalizadas con el copiloto de IA
Ejecutar y rastrear ( trace ) crews de agentes de IA en tiempo real
Desplegar ( deploy ) y monitorear crews en producción
