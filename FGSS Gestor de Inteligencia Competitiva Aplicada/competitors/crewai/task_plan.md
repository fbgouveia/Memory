# Plano VLAEG

## V — Visão

Construir um dossiê reproduzível que converta a superfície pública do CrewAI
(site, repositório MIT, ecossistema GitHub + PyPI) em inteligência
competitiva e requisitos originais para o FGSS.io.

## A — Ações e aceite

1. Coleta aceita somente com manifesto sem ausências, duplicatas ou hashes
   divergentes. Os bugs históricos de `home.html` path collision e falso
   positivo de LICENSE foram corrigidos; o audit atual está `pass`.
2. Snapshot aceito somente com licença e commit de origem preservados.
3. Código aceito como compreendido somente após testes, typecheck, build, lint
   e mapa estrutural — pendentes nesta baseline.
4. Estratégia aceita somente se cada capacidade disser adotar, adaptar ou
   evitar; incluir risco, dependência e métrica.
5. "Injetado no FGSS.io" só poderá ser marcado após implementação e testes no
   repositório real; este subprojeto entrega a especificação executável.

## G — Guardrails

Sem login, compra, formulário, bypass, credencial, dados privados, clonagem de
marca ou inferência de capacidade produtiva a partir de claims comerciais.
Stars, forks e contagens não provam receita ou cliente pagante. Ausência de
proof é `unknown`, nunca zero.
